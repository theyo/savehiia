# Save Home Instead Innovation Academy

This repository contains a web page to help parents communicate with the Temecula Valley Unified School District about preserving the Home Instead Innovation Academy Teacher Directed program.

## Files

- `index.html` - Main HTML page with school board contact information and call to action
- `flyer.pdf` - (Not included) Place your PDF flyer here for download

## How to Use

1. Clone or download this repository
2. Add your PDF flyer as `flyer.pdf` in the same directory as `index.html`
3. Open `index.html` in a web browser or host it on a web server
4. Share the page with other parents

## Hosting

- Any static web hosting service

## Contact Information Included

The page includes contact information for:
- All 5 Temecula Valley School Board members
- District Superintendent
- Assistant Superintendents

All contact information is publicly available from the TVUSD website.
